# Task routing

Before acting, read the topic matching each applicable trigger. Routed rules are mandatory and supplement repository authorities.

- Repository shorthand/next-work requests: [context](repository-context.md).
- Implementation, research, PR review (`./`), dependencies, consistency, or `Assess continuous improvement.`: [select role](../agent-roles/README.md).
- Starting/continuing work, branches, coordination: [admission](work-admission.md).
- Complete prompt/handoff: [persist first](handoffs.md).
- Artifacts, cleanup, branch deletion, review preparation: [custody](artifacts.md).
- Code/document names and references: [durable naming](durable-naming.md).
- Commits/GitHub text: [provenance](github-writing.md).
- PR changes, validation, completion, or entire message `..`: [lifecycle](pr-lifecycle.md).
- Commands/toolchains/module boundaries: [environment](environment.md). Canonical Bash entry: `./arcogine --help`, `check`, `check --full`. On Windows inspect Docker containers first.
- Entire message `.?`: [session-close Kaizen](session-close.md); give deletion verdict.
- Editing instructions: [routing guide](instruction-routing.md).
