Briefing

    Equipment

      Select a machine, then click an empty cell. Cost and limits come from the contract.

      Controls

      • Arrow keys move the floor cursor
      • Enter place the selected machine, or select what is under the cursor
      • Shift+Arrows move the selected machine
      • Delete sell the selected machine
      • Ctrl+Z / Ctrl+Y undo / redo

      The floor is a schematic. Where a machine sits never changes how it processes work; the machine's installation number is its identity.

      Speed changes how fast the screen asks the engine for the next event. It never changes the result.

      Inspector

      Select a machine on the floor.

      Design reports

      Press Check design. Two independent authorities answer: the contract (budget, limits, floor) and the Factory model (can it be published?).
