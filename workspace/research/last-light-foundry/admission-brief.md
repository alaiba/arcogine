## Bounded decision

Adopt a non-spatial, browser-playable factory game that turns the presently implemented Arcogine capabilities into a coherent six-contract prototype, while freezing all existing production source and adding only outward-facing game/integration functionality. The owner asked for a working, challenging prototype exercising all engine features, implemented without core changes, and requested a persisted coding-agent prompt rather than implementation in this session.

This packet proposes the product decisions needed to make that request executable: the Last Light Foundry fiction and loop, six contracts, official reference scoring, stable explicit installation identity, non-consequential floor positions, a serialized runtime bridge, same-build reproducibility boundaries, a meaningful evidence/revision panel, and the acceptance matrix. They are proposed decisions for an owner-opened issue, not already adopted architecture or a concluded first-slice investigation.

The existing first-slice requirement question is still a candidate. Existing strategy-space research supports one mechanical reference, not enjoyment or every new mission; diagnostic research supplies qualified evidence guardrails, not a ready-made production analytics method. Nothing here silently promotes those conclusions further. ## Candidate choice and limits

A pure dashboard would exercise APIs but fail the user's game requirement. A spatial transport/failure-management simulation would require unsupported production semantics or a duplicate simulator, violating the frozen-core constraint. A non-spatial capacity-design game with optional supported availability commands and a provenance-based Engineering panel fits the current APIs and gives the broader modules a meaningful use. That is the proposed choice, subject to the actual build, balance tests and playtest.

Risk is medium for consumer integration and product choices; transport recovery, historical provenance and diagnostic claims require particular care. This packet is a design proposal, not an independently reviewed research conclusion. No core identity, persistence, scheduler or analytical definition is promoted. A newly discovered need to change one of those meanings must return to its existing authority rather than being hidden in an add-on.
